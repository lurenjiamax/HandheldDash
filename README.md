**HandheldDash** is a touch-friendly handheld control panel and a system D-Bus hardware daemon for Arch Linux with KDE Plasma/Wayland. It currently supports and has been tested only on **AYN Thor running the Thorch BSP**; support for other handhelds is planned. [中文文档](README.zh-CN.md). <img src="docs/images/control-panel.png" alt="HandheldDash control panel on AYN Thor" width="620">

It provides performance and fan profiles with editable fan curves, dual-screen brightness and application placement, task switching, region/top/bottom screenshots, playback volume, independent joystick lighting with audio-reactive output and color dials, vibration, configurable Home/Back actions, and gamepad/mouse input profiles. The daemon lets an active local user operate supported hardware without running the interface as root. [Features and limits](docs/features.md).

On a compatible Thorch installation, download `handhelddash-1.0.0-1-any.pkg.tar.zst` from [Releases](https://github.com/lurenjiamax/HandheldDash/releases), install it with `sudo pacman -U handhelddash-1.0.0-1-any.pkg.tar.zst`, then run `sudo systemctl enable --now inputplumber.service aynthor-hardwared.service` and `systemctl --user enable --now aynthor-control.service` in your KDE session. Launch `handhelddash`, open `handhelddash --settings`, or press the AYN key to toggle the panel. [Installation, upgrades and source builds](docs/installation.md).

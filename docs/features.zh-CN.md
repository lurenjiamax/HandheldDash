# 功能与目前限制

支持普通用户通过系统 D-Bus 操作硬件，提供性能预设、CPU/GPU governor、boost、调度器、
风扇预设及自定义曲线、实时温度／转速／PWM、双屏亮度、应用启动屏幕及记忆规则、带图标
和标题及屏幕标记的任务切换、区域／上屏／下屏截图、默认音频输出的音量和静音、左右摇杆
灯光及音频律动、动态归一化和静音门限及平滑、带颜色名和短震的色环、返回／主页键与命令
自定义、手柄／鼠标切换、可选 MangoHud 浮层及 FPS 控制，以及极端实验性的 Android 分区 UI。
同时按住 HOME＋BACK 可重新绑定下屏触控驱动，恢复卡住的触控状态；组合键不执行原有单键动作。
单键动作改在松开时执行，每次恢复后须松开两键才能再次触发。

风扇曲线改为连续线性插值，降温时逐步降速，达到最高温度立即 100%。需配套更新 `thorch-bsp` 的风扇控制器。
风扇可选择随性能联动（安静→安静、标准→均衡、高性能→强散热），也可独立调节；
手动选择风扇预设或应用自定义曲线后自动独立，之后切换性能及智能模式不会覆盖风扇选择。

中控与风扇页共用“随性能／独立调节”状态，停用自动锁定时显示 Caffine。
曲线编辑参考 [FanControl](https://getfancontrol.com/docs/#graph)：预设编辑为自定义后可拖动七个节点，
显示选中温度与 PWM，最后一点保持 100%，明确应用后生效；数值列表默认折叠为高级面板。

设置中的 TAB 管理支持选择常驻页面，其他页面可在设置中临时打开，离开后自动收起。
下屏触控板模式参考 [TouchpadEmulator](https://github.com/CalcProgrammer1/TouchpadEmulator)
的独占输入方式：进入后等待选择 TAB 的手指抬起，再独占物理下屏触控。起始点在触控板内
的接触只输出到虚拟触控板；其他接触转发给映射至 DSI-1 的克隆触屏，保留导航。
KWin 不再收到重复的触控板触屏事件。移动方向读取上屏当前 QScreen 方向，不再固定校正 90°。区域命中与普通触屏转发读取
下屏现有 KDE 校准；方向变化在下一次接触生效，避免进行中的滑动跳变。
离开页面、客户端断开或会话不再活动时释放独占。保留原始时间戳及进行中接触的坐标映射，
不因界面续租延迟中断。独立线程读取原始输入，避免同步硬件及 D-Bus 查询阻塞触控转发；
输入缓冲区溢出时重新读取内核多点接触状态，不再直接丢弃进行中的接触。
KDE/libinput 仍处理手势并提供触控板设置；原始输入迁移默认保留
轻点、关闭轻点拖拽及拖拽锁定，之后保留用户参数。触控板填满页面可用空间，移除触点预览及键盘按钮。
模式显示时通过 KWin 注册 Esc 退出，焦点在上屏应用时仍可返回中控。硬件仍限制采样，已观察到移动帧约 50–55 Hz。新的独占分流交互待用户验证。
实现参考第三方架构，未复制其代码。

目前仅支持并曾在 AYN Thor 上进行真机操作验证。最近的音频映射和输入交互修改没有重新
完成全面真机验证，由用户自行验证；此次发布增加打包，不代表新增硬件验证。CI 只完成
包构建，不检验实际硬件行为，也不包含单元测试。未来计划扩展其他设备。

当前未发现可靠的手柄布局或旁路供电接口；未实现游戏震动的全局强度。上下屏共用实体
音频输出，不能按屏幕独立调整扬声器音量。恒定音量对应稳定亮度，尚未实现节拍检测。
色环摇杆旋转使用手柄模式；鼠标模式使用触控。Android 功能可能完全无法工作，界面明确
警告存在 Android 无法启动的风险。

性能设置新增 UFS 中断位置：CPU0–2、CPU7 或恢复首次设置前配置。动态查找 ufshcd IRQ，
显示允许及实际 CPU，持久保存模式，休眠恢复及每五秒重新应用。CPU7 可能增加功耗，
性能收益取决于负载，尚未测量。屏幕页可分别遮黑上下屏，保持输出与窗口布局，
黑色覆盖窗口请求不获得焦点并拦截触控，AYN 键恢复双屏；不会物理断电或停止后台渲染。
原生手柄没有统一的窗口焦点机制，InputPlumber 支持中控拦截，但固定给某应用需应用配合。
目前充电驱动仅提供阈值等接口，没有已确认的旁路开关，充电分离保持不支持。

中控提供手柄焦点：自动切换、锁定上屏、锁定下屏。锁定模式在收到手柄输入时聚焦目标屏幕
最前的普通应用，自动模式保留当前桌面焦点。直接读取 evdev/SDL 手柄的应用仍可能收到输入，
这不是逐应用设备隔离。未安装自定义应用路由或屏蔽游戏自身的后台手柄输入。

Android userdata 接入 [Thor 挂载文档](https://github.com/lurenjiamax/thorch/blob/feat/thor-custom-kernel/docs/android-userdata-mount.md)
中的独立私有后端。设置 → Android 显示后端就绪情况、服务状态和挂载状态，
提供明确的读写挂载、正常卸载以及打开 `/mnt/aynthor-android/userdata` 的入口。
此目录是 `/mnt/android-data/media/0` 的 bindfs 视图，让普通用户访问而不重写
现有 Android 文件属主和权限；新建条目采用原共享目录属主。
其他支持的 Android 分区仍然只读挂载。挂载前备份数据并验证后端；卸载前关闭
使用目录的应用，并使用 panel 卸载（先清理 bindfs 视图）。清理报错时不要切换系统。不会自动开机解锁、修复文件系统或
配置私有密钥；文件系统已挂载不代表用户文件已成功解锁。

中控温度支持长按选择传感器，列表显示当前数值。功率卡显示电池侧消耗／充电功率，
快充根据 USB PD/PPS 或超过 5.5V 的输入判断。Caffine 名称保持不变，锁图标反映
自动锁定状态。屏幕滑块的图标、文字和轨道同排；点击音量图标静音／取消静音，
不改变原音量。新应用默认屏幕、governor 和调度器采用点击切换／长按列表选择。
截图模式仅保留在中控截图按钮中。独立风扇调节直接选择自定义曲线，曲线和
弹窗数值编辑持续合并写入、即时应用。

设置 → 关于显示源码仓库、安装版本、设备支持范围、授权和无担保声明。
手动部署标为开发版；打包版本由 PKGBUILD 写入，避免版本信息分离。

设置 → 性能中的 MangoHud 仅有“配置释放／配置接管”。接管后重启自动恢复，
统一管理系统采样、限帧和浮层；释放恢复原配置，并停用中控限帧和浮层控制。
游戏显式指定的 MangoHud 配置仍可能优先生效。限帧使用 30／60／120 数字矢量图标，
不限帧显示 ∞。

按键设置新增 Back + Home，同时按下默认重置下屏触控驱动，可改为其他动作。
任务切换支持中文进程名和其他用户的窗口。AYN 唤出面板保留游戏焦点；
显式打开设置允许获得焦点以输入文字。GPU、功耗和充电分别使用显卡、闪电
和充电插头图标。

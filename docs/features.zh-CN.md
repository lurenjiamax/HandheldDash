# 功能与限制

- 通过 Thorch 后端调整性能与风扇曲线。
- 使用弹窗调整亮度、音量、振动和手柄方案。
- 音量弹窗提供系统默认、软件音量、硬件音量，按 ALSA 或蓝牙设备分别保存，需要 WirePlumber 0.5 以上。软件模式绕过硬件的粗粒度音量档位。切换会短暂重连音频，并保留输出设备、音量和静音状态。硬件模式优先使用设备支持的硬件混音器，不支持时仍可能使用软件混音。系统默认只移除 Dash 对该设备的覆盖，不修改其他 WirePlumber 配置。
- 移动控制卡片，按需添加监控卡片。
- 通过 KWin 管理窗口位置、任务切换和截图。
- “窗口焦点”提供自动、锁定上屏、锁定下屏选项。
- 锁定上屏时 Dash 不主动获取键盘焦点。屏幕焦点锁定选项在另一屏桌面之上、普通应用之下显示透明触摸隔离层，自动模式将其移除。其他应用和主动打开的设置仍能获取焦点；双屏键盘焦点仍为全局共享。
- 暗屏将亮度归零并独占对应触摸屏，保留显示布局；按 Dash 实体键恢复原亮度与触摸。面板扫描可能继续运行。Dash 断开时自动恢复，硬件服务重启时从恢复记录还原亮度。
- 长按任务，通过触摸勾选 CPU 核心并应用亲和性；支持按小核、中核、大核分组选择，显示硬件最高频率。
- 调整摇杆灯光、硬件按键及可选的 Android 存储访问。

弹窗选择即时生效，点击外部关闭。中控布局通过勾号保存。

CPU 亲和性需要点击“应用”。初始选择读取主线程，应用覆盖进程现有线程，不修改已有子进程，也不保存为下次启动规则。核心等级优先按硬件算力分组，缺失时按最高频率分组。

监控只采集已选项目，缺失数据显示为破折号。

目前已验证的环境为采用 Thorch BSP 与 KWin 的 AYN Thor。不支持的功能会禁用。手柄焦点无法隔离多个游戏的控制器输入。MangoHud 提供限帧与可选的游戏内叠加层，中控不再采集帧率日志。

Android 存储功能属于实验功能，可能影响 Android 启动。旁路供电和手柄布局切换尚无已验证的后端。

Android 共享存储直接使用内核 idmapped bind mount，将调用用户的 UID、主 GID
分别与原始 media 目录的属主 ID 交换，其他有效 Linux ID 保持原映射，不改写文件属主。
共享视图允许执行程序，保留 nosuid、nodev，硬件服务重启不影响挂载，也不依赖用户态
文件系统进程。挂载、打开和卸载共用同一套归属识别。文件权限、ACL、chmod/chown 和
xattr 遵循底层文件系统语义，移除旧 FUSE 权限改写。需要 util-linux 2.39 以上以及支持
idmapping 的内核和文件系统；不支持时直接报错，不使用其他挂载后端。
